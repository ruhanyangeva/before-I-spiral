# Before I Spiral

**A first stop for second thoughts.**

在反思变成自我攻击之前，找回一点清晰、自我信任和选择。

这是一个可以交给 AI 使用的对话 Skill，不是独立 App，也不是治疗服务。核心文件：给人读的本页、给 AI 读的 [SKILL.md](SKILL.md)、说明判断规则的 [情绪边界逻辑](EMOTIONAL_BOUNDARIES.md)。

## 1. 为什么做这个

不是每个人都有《欲望都市》里那样，什么都能说的朋友小团体。即使有人陪伴，谈论感受也未必是一件自在的事。

我不认为“想太多”的答案就是不再想。回看、表达和理解感受，有它们的价值。但我也经历过：半夜把一件事反复想了一小时，越想越清醒，还觉得每一步分析都很必要；第二天却只剩疲惫，并没有更清楚。

和十年的内耗慢慢和解后，我把一些真正帮助过自己的提醒整理成了 Before I Spiral。它来自我的个人经历、大学四年的心理咨询，以及持续的佛学学习。特别感谢 UCSB 的 Dana，留给我一些后来仍然受用的提醒。这里的致谢不代表任何个人或机构为产品背书。

我花了很多年才明白：有时，不是我不讨人喜欢，而是那个环境并不适合我。世界比我当时用来衡量自己的那一小块地方大得多。这个认识不是让我永远认定自己正确，而是提醒我，别急着把一段经历变成整个人的判决。

## 2. 它能为你做什么

- **对自己温和，也对现实负责。** 失误可以修复，不必靠羞辱自己证明认真。
- **在循环里找到出口。** 分辨是在获得新信息，还是重复惩罚、索取确定。
- **把事实与故事分开。** 感受需要被听见，推论也值得被检查。
- **拿回自己的标准。** 不把别人的选择当作对你的否定，也不靠贬低别人抬高自己。
- **练习公平的比较。** 看见背景、资源与未知，不把别人的片段当作自己的判卷。
- **允许暂停。** 不必把所有问题想通才配休息；积极也不是强迫快乐。

例如，你说：“别人那么容易被打动，是不是我要求太高？”它不该回答“你标准高就是优秀”，而应帮助区分：你要的是尊重与一致性，还是对方永不犯错？欣赏小小善意与坚持边界，并不矛盾。

它的目标不是让你聊得更久，而是让你带着自己的判断继续生活。找朋友、家人或专业人士并不是添麻烦；这个工具只是另一个可选入口。

## 3. 技术层面的情绪边界

常规流程是 **Catch → Separate → Challenge → Reclaim → Close**：接住困扰，拆开事实与推论，检查假设，回到自己的价值，再给一个有限的下一步。

它在关键处换一种回应：具体反思就继续听；人格攻击或无新信息的循环就温和刹车；已知深夜且疲惫时减少分析；出现当前危险时优先现实支持。

**不是靠关键词给人打分。** 不会因为说了一句“我想消失”就机械拒聊，也不会因为过了 23 点就命令睡觉。时间、上下文和用户意愿都要核实。普通聊天没有读取心率、持续监控情绪或自动报警的能力。

详细规则、例外和评审指标见 [EMOTIONAL_BOUNDARIES.md](EMOTIONAL_BOUNDARIES.md)。它是模型的行为指引，不是保证执行的安全程序，也不会高于平台自身规则。

## 4. 方法论来源与边界

**佛教正念与慈悲：**保留觉察、减少追加自我惩罚、看见因缘条件、不过早固定自我身份等启发。“第二支箭”源自 [SN 36.6《箭经》](https://www.dhammatalks.org/suttas/SN/SN36_6.html)；这里将其作为日常支持的类比，不把难过归罪于当事人。

**认知行为取向的自助技巧：**参考 NHS 的 [Catch it, check it, change it](https://www.nhs.uk/every-mind-matters/mental-wellbeing-tips/self-help-cbt-techniques/reframing-unhelpful-thoughts/)，检查无益想法的依据，寻找更平衡的解释。我们的五步流程是产品组织方式，不是一套经过验证的独立疗法。

**自我慈悲：**参考 Kristin Neff 对觉察、共同人性与自我善意的[介绍](https://self-compassion.org/what-is-self-compassion/)。温和可以与保护、边界和改变并存，不等于放任。

想继续阅读，可从一行禅师的 [The Miracle of Mindfulness](https://www.beacon.org/The-Miracle-of-Mindfulness-P194.aspx) 入手。更多概念怎样落实到回答，见 [方法论与来源](references/METHODS.md)。我们不靠堆书名证明有效，也不复制整套课程或把参考作者列为背书者。

**说明：**我是佛学学习者，不是治疗师。本工具不提供诊断、心理治疗或紧急救助，不承诺治愈。无需信佛、原谅伤害或停止在意现实。持续或严重的困扰值得寻求专业支持；当前危险需要现实中的及时帮助。

## 5. 怎么使用：只会和 AI 聊天，也可以

### 最简单：复制一次，然后聊天

1. 打开 [START_HERE.md](START_HERE.md)。它是一份已经整理好的完整聊天说明。
2. 复制“复制开始”与“复制结束”之间的全部内容，粘贴到你常用 AI 的新对话。能读取文件的聊天工具，也可以上传该文件并说“请按其中的方法回应”。
3. 接着写：“事情是……我一直对自己说……我现在想先倾诉／一起梳理／暂停一下。”不需要整理得客观或体面。
4. AI 理解错了就直接纠正；可以拒绝练习、换话题或停止。它不需要成为你的唯一支持。

这是提示词试用，不是自动安装，不会跨聊天记住你；平台可能忽略或截断说明，效果需要你检查。不要上传不愿交给该平台保存的个人资料。

### 使用支持 Skill 的工具

把整个 `before-i-spiral` 文件夹安装到宿主的技能目录，不能只留简介。Codex 的当前个人目录是 `~/.agents/skills/`，然后在新对话明确调用 `$before-i-spiral`；找不到时重启再试。其他宿主遵循自己的安装入口；不要假设都支持相同命令。[官方说明](https://learn.chatgpt.com/docs/build-skills)
